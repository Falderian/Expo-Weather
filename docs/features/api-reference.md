# API Reference

Open-Meteo endpoints used by the app.

---

## Current Endpoints

| Endpoint | Purpose | Auth |
|----------|---------|------|
| `api.open-meteo.com/v1/forecast` | Current + hourly + daily weather | None |
| `geocoding-api.open-meteo.com/v1/search` | City search | None |

## Planned Endpoints

| Endpoint | Purpose | Auth |
|----------|---------|------|
| `air-quality-api.open-meteo.com/v1/air-quality` | AQI data | None |
| `archive-api.open-meteo.com/v1/archive` | Historical weather | None |

---

## Notes

- All Open-Meteo APIs are **free** and require **no API key**
- Rate limits apply (reasonable use)
- Responses are in JSON format
