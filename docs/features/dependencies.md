# Dependencies

Packages to install for planned features.

---

## By Feature

| Package | Feature | Purpose |
|---------|---------|---------|
| `expo-notifications` | Weather Alerts | Push notification support |
| `expo-widgets` or equivalent | Home Screen Widgets | Native widget rendering |
| `react-native-maps` | Weather Maps | Map overlay rendering |
| `expo-localization` | i18n | Device locale detection |
| `i18n-js` or `react-i18next` | i18n | Translation management |
| `lottie-react-native` | Animated Icons | Lottie animation rendering |
| `@react-native-community/netinfo` | Offline Caching | Network status detection |
| `react-native-view-shot` | Weather Sharing | Screen capture |
| `expo-sharing` | Weather Sharing | Native share sheet |
